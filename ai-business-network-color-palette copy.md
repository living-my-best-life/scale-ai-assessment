# AI Business Network Color Palette

A reference guide for agents and designers working with AI Business Network brand colors.

---

## Primary Colors

| Color | Hex Code | Usage |
|-------|----------|-------|
| Deep Purple/Black | `#0a0619` | Primary background, dark themes |
| White | `#ffffff` | Text on dark backgrounds, light themes |

## Accent Colors

| Color | Hex Code | Usage |
|-------|----------|-------|
| Ocean Blue | `#35a0c4` | Links, secondary accents |
| Royal Blue | `#216fdf` | Primary CTAs, highlights |
| Mint Green | `#57ec99` | Success states, positive indicators |
| Coral Orange | `#fc8852` | Warnings, warm accents |
| Hot Pink | `#fc4e99` | Creative emphasis, bold highlights |
| Teal | `#39b6ba` | Secondary actions, balanced accents |
| Golden Yellow | `#fcae26` | Alerts, attention-grabbing elements |

---
